# Codex adapter

Read applicable AGENTS.md and the project's continuity mapping first. If a protocol release is pinned there,
read that exact SKILL.md and follow its routed resources. Do not substitute the personal default for a project pin.
If no mapping exists, read the default protocol at `@PROTOCOL_PATH@` and follow its onboarding workflow.
Resolve referenced resources relative to the protocol directory, not this adapter or the working directory.
Use the available shell/Git tools and the project's own validation commands; lack of quota telemetry does not block closeout.
Treat “full handoff” or “quota low” as closeout triggers. Read the previous current record before continuing authorized work.
Missing protocol is an explicit dependency problem, not permission to improvise a conflicting workflow.
This adapter carries no business rules or copy of the protocol. Explicit invocation: `$alternating-agent-development`.
